Configuración de una Red Pequeña

De la conexión física a la identidad lógica: componentes y parámetros clave.

Iniciar Recorrido Interactivo

1. Hardware de Red Esencial

Pasa el cursor o haz clic sobre los componentes físicos para conocer su función:

Tarjeta de Red (NIC)

Permite al dispositivo conectarse físicamente mediante cable Ethernet o de forma inalámbrica vía Wi-Fi.

Cable UTP / Medio

Medio físico de transmisión de datos compuesto por hilos de cobre trenzados con conectores RJ-45.

Switch (Conmutador)

Conecta múltiples equipos formando una red local (LAN), permitiendo la comunicación interna entre ellos.

Router (Enrutador)

Dispositivo inteligente que conecta diferentes redes entre sí, permitiendo el tráfico hacia Internet (WAN).

3. Parámetros Lógicos de Configuración

Dirección IP

192.168.1.10

Identificador único del host dentro de la red.

Máscara de Subred

255.255.255.0

Delimita qué parte de la IP pertenece a la red y cuál al host.

Default Gateway

192.168.1.1

IP del Router que permite salir a redes externas.

Servidor DNS

8.8.8.8

Traduce nombres web legibles a direcciones IP numéricas.

4. Asignación de Direcciones IP

Dinámica (DHCP)

El router asigna una IP automáticamente al conectar el dispositivo. Ideal para laptops y smartphones.

Estática (Manual)

Configurada de forma fija por el administrador. Esencial para servidores e impresoras de red.
